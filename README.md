# Gratis DB

Optional SQLite WordPress database module. Part of the [Gratis Suite](https://gratis.superglobalsdevelopment.com).

## ⚠️ Safety First
- Never silently replaces MySQL
- Provides compatibility scanner before migration
- Full rollback workflow
- Safety warnings at every step

## Features (planned)
- `db.php` drop-in manager
- MySQL → SQLite migration planner
- SQLite → MySQL migration planner
- SQLite backup snapshot support
- Compatibility scanner (plugin/theme compatibility)
- WP-CLI commands for migration management

## Requirements
- PHP 8.0+
- ext-sqlite3
